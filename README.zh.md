# mind_map · 思维图

[English](README.md) | 中文

DeepSeek Harness（dsh）的可视化思维图插件：**一个会话就是一个点**，所有会话连成一张会自己找平衡的云图。

> 源自 [Tasihi89/mind_map](https://github.com/Tasihi89/mind_map)（MIT）。本仓库是在其基础上大幅改造的分支。
> **2026-11-19 大修：卡片白板模型（槽位布局 / 工作区框 / 溢出抽屉 / 卡片连线）已彻底删除，只保留云图模型。**

- **一个点就是一个会话**：像 Obsidian 的图谱视图。平时只画点，**鼠标移到点上才显示这个会话的标题**（标题画在屏幕空间，缩到很小也看得清）。
- **连线越多，点越大**：点的半径只由它有多少条连线决定（`r = 1.7 + 1.3·√度数`，上限 11px），所以枢纽会话一眼就能认出来。
- **关键词自己也是节点**：一个标签 = 一个空心蓝环的「key 点」，会话连到它命中的关键词上 —— 被越多会话用到的 key 越大；悬停看到 `#标签 · N 个会话`，点一下就把它和它那一圈会话钉住高亮。
- **三种关系，三种颜色的线**：同一个工作区（冷灰）、同一个标签（蓝，走上面的 key 点）、子代理 / 分叉血缘（暖橙）。
- **斥力 + 硬芯，点不会叠在一起**：持续力导向模拟，全对全斥力把点推开，两点的圆之间还有一圈固定余量（收敛尾段和落库前各做一次纯几何去重）。
- **正在跑的会话会缓慢闪烁**：呼吸的光晕（周期约 3 秒），不是快闪。
- **悬停高亮与聚焦**：悬停一个点 → 它和直接相连的点保持明亮、其余压暗、它的连线加粗；「聚焦」只点亮当前会话那个点，其余全部压暗。
- **双击空白即聊**：双击空白处就地新建一个会话。**shift 从点上拖出**一根橡皮筋到空白 → 预览（可编辑）要注入的上下文摘要，确认后开一个「带着旧对话记忆」的新会话。
- **按需摘要 / 标签**：三字段摘要（概要 / 关键结论 / 下一步）用你部署里的默认模型生成；顶栏「🏷 生成标签」给还没有标签的会话批量生成标签（标签就是云图里蓝色的那些线）。
- **归档可隐藏**：默认隐藏已归档会话和别的会话跑完的子代理（顶栏开关，状态记在浏览器里），归档的点灰化显示。
- **状态栏**：地图左侧可收起的条，只列当前有状态灯的会话（运行中 / 等你回复 / 待查看 / 异常终止），点一条就把镜头缓动到那个点上。
- **中英双语界面**：地图顶栏那颗药丸按钮循环切换 自动 → 中文 → English，「自动」跟随 dsh 本身的语言，选择会记住。

## 安装

```sh
# npm（推荐）
dsh plugin add mind_map

# 或直接从 GitHub 装——构建产物已随仓库提交，免构建
dsh plugin add github:Da0Mine/dsh-talk-map
```

重启 `dsh web`，侧栏底部出现地图按钮。

## 用法

| 操作 | 效果 |
|---|---|
| 侧栏地图按钮 / Esc | 打开或收起地图 |
| 拖卡片 | 摆放（16px 网格吸附，会保存） |
| 双击空白处 | 在那里新建会话并进入 |
| 双击卡片 | 打开那个会话 |
| 从卡片接口拖到空白处 | 预览注入内容 → 分叉出新会话 |
| 点堆叠格 | 打开抽屉，列出被折叠的会话 |
| 卡片上的 ⟳ | 重新生成摘要 |
| 右键卡片 / 连线 / 工作区 | 置顶、重命名、标为未读、查看摘要、归档、删除、推送开关、删除连线 |
| 顶栏语言药丸 | 循环 自动 → 中文 → English |

## 数据放在哪

- 画布数据（位置、连线、摘要）：`$DSH_HOME/storages/mind_map.json`，走 dsh 官方 storage-domain，原子写入。
- 会话本身完全归 dsh 所有——本插件只读它们，只有分叉时才通过官方 API 新建。
- 摘要走 dsh 本地 LLM 通道使用你配置的默认模型，没有其他外部请求。

## 兼容性

在 DeepSeek Harness `0.2.1-rc.3` 上构建与验证。结构契约在 `src/client/dsh.ts` 与 `src/host/dsh-host.ts`，升级时从这两处入手。

## 开发

```sh
pnpm install
pnpm run build        # 宿主 → lib/，客户端 → client/client.js
pnpm run probe        # 无头端到端探针（150 项）
dsh plugin --profile dev add /abs/path/mind_map
```
