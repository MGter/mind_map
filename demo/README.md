# 思维图 · 交互演示页

**双击 `index.html` 即可打开**——这不是模拟页，是插件**真身**在浏览器里跑：页面加载的是 `client/client.dev.js`（插件客户端构建产物）+ `test/harness.js`（离线宿主桩），所以渲染、交互、样式与 DSH 里的面板 100% 一致。

无构建、无网络请求；file:// 直接可用（演示模式通过 `window.__mindMapDemo` 开启，不依赖 URL 参数）。

## 演示数据（全部虚构）

打开演示页时，harness 整体换成虚构数据集，**不含任何真实会话内容**：

- 6 个工作区：产品设计 / 内容运营 / 灵感速记 / 物理备课 / 旅行计划 / 团队共享
- 25 张卡片（官网改版、周报汇总、力的合成课件、长沙行程……），其中 3 张是不属于任何框架的自由卡
- 3 条连线：2 条存储线（未同步 → 虚线可见）+ 1 条父子分叉线（物理备课框架内）
- 灯牌覆盖：运行中（白光环流光）、等待回复（黄）、待查看（绿）、异常（红）
- **待发送示例**：两张卡带「待发送」chip（板上的"长沙行程规划"、抽屉里的"海报文案三选一"）——harness 直接往 `dsh.conversation.<id>` 里预置了未发送草稿，和真实输入框行为一致
- 摘要（digest）也整体替换为虚构内容

### 布局自动保存

演示页把每次写操作（拖卡、挪框架、连线、删除…）镜像进 localStorage（`mind_map.demo-state.v1`），**刷新/重开后布局保持**。想恢复出厂演示布局，清掉这个键即可（F12 → Application → Local Storage）。

探针（`node test/probe.mjs`，不带 demo 参数）仍用原 fixture，150/150 不受影响。

## 能玩的功能

| 功能 | 操作 |
|---|---|
| 画布平移/缩放 | 空白拖动 / 滚轮（以光标为中心） |
| 卡片拖拽、框架整体拖动 | 按住卡片或框架边框 |
| 工作区堆叠抽屉 | 框架标题旁徽标 → 抽屉（产品设计 8 个对话） |
| 抽屉内搜索过滤 | 抽屉顶部输入即时过滤 |
| 全局搜索 | 顶栏搜索框输入「官网」回车 → 高亮命中 + 点击定位 |
| 连线绘制 | 从卡片左右边缘把手拖到另一张卡 |
| 卡片右键菜单 | 置顶 / 标未读 / 重命名 / 查看摘要 / 归档 / 删除 / 批量 |
| 连线右键菜单 | 推送摘要 / 开启自动推送 / 删除连线 |
| 双击空白 | 原地新建对话 |
| 字号 A−/A+/默认 | 顶栏按钮 |

## 改了插件代码之后

演示页加载的是 `client/client.dev.js`，所以改完 `src/client/` 要先跑：

```
node scripts/build-client.mjs        # 只出 dev 构建，给演示页用
```

（`--publish` 才会写 `client/client.js` 影响真实 DSH。）
